# Automated Portfolio Status and Forecasting Pack

**Yuva Intern – Data Science Project Coordinator Project**

## Overview

This project focuses on developing an automated project portfolio tracking and forecasting system for managing six concurrent data science projects.

The system aims to improve project visibility, identify delivery risks, monitor performance and generate consistent management reports.

## Objectives

- Track multiple data science projects.
- Monitor planned versus actual progress.
- Automate Red, Amber and Green (RAG) status classification.
- Monitor project costs and effort consumption.
- Identify missing and delayed weekly updates.
- Track project blockers and issue ageing.
- Develop management dashboards and forecasting reports.

## Tools and Technologies

- Microsoft Excel 365
- Excel Formulas
- XLOOKUP and MAXIFS
- Conditional Formatting
- Excel Charts and Dashboards
- Power Query (planned)

## Project Modules

1. Project Master Tracker
2. Weekly Historical Updates
3. Progress and Effort Variance Analysis
4. Automated RAG Status Engine
5. Portfolio KPI Dashboard
6. Issue Ageing Tracker
7. Earned Value Management
8. Project Forecasting and Reporting

## Dataset

The project uses synthetic data representing six data science projects over eight weeks. No real company or customer data is used.
