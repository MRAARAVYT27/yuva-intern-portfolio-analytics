# Yuva Intern – Project Portfolio Status & Forecasting Pack

## Overview
An Excel 365 portfolio tracking and reporting workbook for six synthetic data science projects. It consolidates weekly progress, reporting timeliness, RAG health, issue ageing, dependencies, milestones and Earned Value Management (EVM) indicators.

## Workbook
`Yuva_Intern_Portfolio_Status_Reporting_Pack.xlsx`

### Included sheets
- Executive Summary
- Project Master
- Start Here
- Data Dictionary
- Weekly Updates
- Phase 2 Guide
- RAG Rules
- Portfolio Summary
- Issue Log
- EVM & Forecast
- Milestone Tracker
- Dependency Register

## Key capabilities
- Planned versus actual completion and progress variance
- Reporting alerts for on-time, late and missing updates
- RAG status classification
- Portfolio KPI summary and charts
- Issue age, ageing category and severity
- PV, EV, AC, SV, CV, SPI, CPI, EAC, ETC and VAC
- Indicative SPI-based forecast finish dates

## Data and assumptions
All project names, owners, budgets, progress, costs and weekly records are synthetic sample data. The workbook contains six projects and 48 weekly records. Milestone dates are illustrative proposals because approved milestone baselines were not present in the source files. Dependency actions are recommendations derived from blocker comments. Forecasts are indicative and require project-owner validation.

## Files
- `workbook/` – final Excel workbook
- `reports/` – sample weekly portfolio status report
- `documentation/` – methodology and usage guide
